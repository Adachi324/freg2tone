## Brand & Style

已确认方向：首先像在玩一款音乐冒险游戏。用户喜欢线稿、手绘绘本氛围、翻页的感觉，以及由平面进入立体世界的体验；《勇敢小骑士》是氛围和过渡参考。弱化实体书概念，不以书封、书脊、课本或课堂作为主要视觉识别。用户不满意概念图 v2 的手绘表现，在比较现代可爱与复古手绘后认为复古候选更接近预期，但颜色偏暗。目前同意保留《茶杯头》参考方向的墨线、夸张造型与弹性表现，配色改为明快轻松，减少泛黄、做旧和重阴影。用户查看明亮版后认为又太亮，要求在暗版与亮版之间折中；当前色彩目标为柔和、中等亮度与适度饱和。调色仍在讨论，不将方向认可扩大为角色、机关或最终美术定稿。

本文件为讨论中的草稿，未定稿；已确认偏好与下文提案分开记录。教学 UI 方向已于 2026-09-28 获认可，具体色值、尺寸和其余场景组件仍未冻结。概念图里的花园、乐器和石门只是视觉示例，不代表课程或机关玩法已选定。

用户未接受的[概念图 v2](.working/hybrid-world-v2.png)保留为探索记录，不作为美术基准。[生成提示词与修订记录](.working/hybrid-concept-prompts.md)保留来源。[新一轮风格比较](.working/art-direction-comparison-2026-09-21.md)使用相近的场景布局比较线条、造型与色彩，暂不同时决定教学布局或动画实现。

## Colors

已确认原则：清晰墨线与柔和色块共存，亮度和饱和度在原始暗版与明亮版之间折中。避免大面积灰褐底色、重阴影，也避免过亮底色和高饱和蓝绿红黄。保留构图、造型和轻微手绘质感。具体色值尚未冻结；参考图只作视觉讨论，不是 UI 对比度验证。

用户认为[明亮配色候选](.working/style-retro-bright-2026-09-22.png)偏亮，当前转为折中调色；[编辑记录与提示词](.working/bright-retro-edit-2026-09-22.md)。

2026-10-16 已确认调整：首个样本始终使用固定立体花园；纸面板承载知识介绍、示范、练习与回看。练习后收起教学，保留简短任务提示，立即操作机关；不固定安排整场2D→3D翻转。维度切换留待确有玩法价值时考虑。

教学 UI 参考：[教学三状态画稿](.working/key-learning.html)，展示介绍展开、对照示范与引导练习。2026-09-28 用户确认若仅确定教学 UI 则没有问题，沿用当前说明区风格与三状态组织作为后续设计基准，具体尺寸和字体参数留待实现检查。

## Do's and Don'ts

- 保留手绘绘本气质与游戏感，弱化实体书识别。
- 知识介绍必须可见、可读，不能为了游戏氛围删去概念解释。
- 概念图不作为具体乐理映射、最终组件尺寸或完成的 3D 资产。
- 本文及 EXPERIENCE.md 中已确认的要求优先于画稿；提案不因出现在画稿中而自动成为已确认决定。
