学到的东西，怎样改变眼前的场景？

待评审布局提案 · 静态流程线框，非可玩 Demo。六张横屏画面依次展示进入、知识介绍、对照示范、引导练习、独立挑战和结果。几何线条仅表达固定 3D 镜头下的空间关系，不确定最终美术风格。

当前已确认：横屏 / 平面与固定镜头 3D 混合 / 独立小场景 / 点选后自动靠近。这份较早的灰度线框保留六阶段流程，尚未适配最新的平面与立体混合表现。此处提出的机关、材料摆放、提示方式与通行反馈仍是候选；具体课程规则待定。所有画内按钮均为静态示意。

01 找到可以操作的装置

进入场景 → 点选装置 → 角色自动靠近

制作说明：玩家先看见一个可改变的场景目标。点选目标区域即可行动，镜头方向保持固定。虚线仅表示待评审的引导方式。

02 先认识两个概念

介绍是什么 → 说明用途 → 再看例子

制作说明：新增的知识介绍是独立可读状态，不用“点这里”的操作提示代替。示例短文只展示教学区的容量与层次，不是完整教案；唱名体系、对应规则和适用范围在内容制作时明确。教学可按需要拆成多个小段，不要求全部挤在机关旁。

03 把知识与一个例子连起来

系统示范 → 声音与标记对应 → 可重复观察

制作说明：这里由系统示范并解释知识关系，尚未要求玩家答题。具体名称与关系暂用占位，必须由后续教案填入正确的适用规则；无声时可看文字与高亮回放，不能据此认定听觉学习完成。静态画稿不播放声音。

04 在帮助下应用刚学的知识

回顾知识关系 → 玩家尝试 → 解释反馈

制作说明：说明贴近正在操作的装置；音乐材料在场景内。音频、名称高亮与装置局部变化同步。音符甲/乙/丙与名称标记均为占位，不代表真实课程映射。

05 撤去提示，自己完成

只保留目标 → 独立选取 → 可替换重试

制作说明：下一处同类装置使用已学操作。撤去名称与材料的对应提示，材料位置可变化。错误后保留场景与已完成操作，给出局部反馈；可替换材料，也可主动回看教学，回看后的完成不能视为独立通过。

06 让结果发生在场景里

声音响应 → 装置改变 → 角色自动通行

制作说明：成功首先由声音和装置状态确认，再展开通路，角色自动通过。先展示改变，再出现“继续”，保持音乐操作与世界结果的因果关系。通路仅为当前示意机关，不代表所有课程都用开路玩法。

这轮画稿要检查什么

是否真正教过：玩家是否先看到了概念解释和完整示例，再被要求练习？引导练习能否连接到刚介绍的知识？

场景能否读懂：第一眼能否找到角色、可操作装置、音乐材料以及受影响的通路？

动作是否自然：点选目标、角色靠近、选取材料并安装的流程是否符合期待？精确的触控/鼠标手势尚未定稿。

反馈是否足够：相较于答对后只出现文字，装置变化与角色通行是否更接近期望的“学到的东西真的有效”？

本文件不播放声音、不运行 3D、不判题，不能用于证明音视同步、教学有效性或设备性能。无声情况下仅能表达可视结构与操作；听觉学习须在后续可玩版本中验证。
