# 吉他演奏与扒歌的乐理短课程 v0.1

> 2026-11-10 状态更新：已授权第一章 Web 产品改造；下文“不开发网页”“尚未真人试教”为历史阶段描述。2026-11-05 仅有用户转述文字模拟试学，详见 lesson-01/trial-feedback-2026-11-05.md，听觉、实琴与隔天保持未验证。第二章仅作后续规划，本轮不实现。当前执行依据为 ../../specs/spec-learning-web-v1/SPEC.md。

## 已确认方向与本稿性质

用户长期目标分两步：先将乐理用于吉他演奏与扒歌，再走向编曲。当前知道音程、大调音阶、常用和弦及组成，但主要照谱演奏，尚不能稳定应用，已尝试分析段落使用的音阶。

本轮先设计课程顺序与每节目标，不开发网页。采用教学者统一选择的概念示例、代表性曲例与练习，再迁移到个人曲目；先验证学习效果，游戏不作为验证前提。

以上为本次对话确认；2026-11-04 用户已认可下列课程顺序，并要求先细化第一节，不做网页。具体材料限制及评价办法仍为待试用草案，不是经验证有效的教学法。旧产品简报的“成年零基础、通用乐理、不限定乐器”和游戏优先的近期路线，不用于约束本轮课程；旧文档与实现保留为历史成果，本稿不宣告全产品定位已永久改变。

第一节已细化为[可试教教案](lesson-01/lesson.md)、[独立练习纸](lesson-01/practice.md)和[教师答案与评价](lesson-01/teacher.md)。已计算核对音程与指板位置；尚未真人试教。

## 课程终点与范围

完成后，面对教学者选定的、速度适中、节奏简单、无转调、以调内旋律和基础和弦为主的短片段，能够：

- 结合旋律与伴奏提出调性判断，并说出依据与不确定处。
- 把主要旋律音写成音名和级数，在一个熟悉的指板区域找到并弹出。
- 分析和弦组成、级数及旋律中的和弦音，用这些关系缩小找音和找和弦的范围。
- 在允许循环、放慢及提供参考音的情况下，尝试扒出短旋律和简单伴奏骨架，再用谱例核对。
- 构造并对照聆听大、小三和弦及 maj7、7、m7；不把组成知识等同于稳定听辨。

“常用音阶”本轮限大调、自然小调、大/小五声音阶；“和弦色彩”限上述类型及具体语境中的对照。暂不含全指板熟练、全部调式、和声/旋律小调系统、蓝调语汇、复杂节奏听写、任意录音完整扒谱或编曲。自然小调单元不据此概括所有小调歌曲。

## 顺序与每节目标

这里的“一节”是一个学习单元，可拆成多次短学习，不承诺一次十分钟掌握。先诊断，已会内容可略讲，但仍需通过新的应用题。

| 单元 | 核心问题与知识 | 学完可观察的能力 | 统一材料与检查 |
| --- | --- | --- | --- |
| 0. 起点诊断，不计正式课 | 哪些知识能说、能听、能弹？ | 给出当前能力基线，不提前教学或以自述代替表现 | 大调组成、熟悉和弦拆音、给根音找三/五音、短旋律模仿各取少量样本；允许不知道；补足调弦、拍点或音名缺口 |
| 1. 把音程落到指板上 | 音名、半音距离和指板位置怎样对应？ | 给定根音，在限定区域找并弹出大/小三度与纯五度，说明音名和关系；能用高低方向与参考音修正选择 | 标准调弦、单弦起步再到相邻弦；标出 B 弦调弦差异，换根音检查；不要求背全指板或无参考音辨音 |
| 2. 大调里的音有位置 | 音阶公式怎样变成旋律中的级数？ | 从主音构造大调，把短旋律音名转成级数；给新主音后移调一个短动机并弹出 | C 大调入门、G 大调迁移；简单节奏的 2–4 小节旋律；先听主音与伴奏，再找落点；听完能回唱或在琴上找到主音 |
| 3. 同一组音，为什么不是同一个调？ | 主音、调性与相对大小调 | 比较 C 大调/A 自然小调的同音集合，结合持续主音、伴奏和句末落点判断中心；解释为什么只列音集合不够 | 同音集合、不同中心的成对短例；再用 G 大调/E 自然小调迁移；包含一个证据不足的例子，允许不确定；不把首音/末音当作必然主音 |
| 4. 从和弦指型看到组成音 | 根音、三音、五音；大/小三和弦；重复音和转位 | 拆解熟悉吉他和弦中的音并标角色；构造或修改一个简易三和弦，说明只改三音如何改变性质；理解最低音不一定是根音 | C、Am、G、Em 等熟悉指型用于拆音；听觉对照使用同根、同音色、相近排列的大/小三和弦，避免指法难度干扰；另用三音简易指型操作 |
| 5. 和弦怎样在调里连接？ | 调内三和弦、罗马数字、基础进行与和弦音 | 从大调音阶推导调内三和弦；把 C–F–G–C 写为 I–IV–V–I 并迁移到 G 调；标出旋律中的和弦音，用根音、组成和解决关系比较伴奏候选 | 先 I–IV–V–I，再 I–vi–IV–V；核心操作只用 I、IV、V、vi；ii、iii、vii°用于展示完整推导，不要求全套听辨；用有明确终止的材料听比较稳定与待继续的感觉 |
| 6. 五声音阶怎样服务旋律？ | 大/小五声音阶与已学七声音阶的关系 | 从大调/自然小调得到相应五声音阶；在限定把位辨认一句五声音阶旋律，说明其音级及和弦落点；把同一动机换到新主音 | C 大五声与 A 小五声对照，之后换 G/Em；不只背指型，不声称五声音阶任意音在任意伴奏上都同样合适；不引入蓝调大小混用 |
| 7. 七和弦的组成与色彩 | maj7、7、m7 的三音、七音差异 | 写出并构造三种七和弦；听相同根音的对照指出变化，能说明具体听感与组成的关系；在 C 调中分析 Cmaj7、G7、Am7，观察 G7→C 的解决 | 先三和弦加七音，再对比 Cmaj7/C7/Cm7；同根对照不代表三者都属 C 大调；吉他用预选可弹指型或分解音，不要求临时掌握高难按法；不把“大=快乐、小=悲伤”设成判分标准 |
| 8. 综合分析与第一次受限扒歌 | 把音阶、音程、和弦关系连接成方法 | 对陌生短片段提出调性假设，找旋律级数和和弦骨架，弹出核对并说明怎样修正错误；区分听到的证据与推测 | 分两部分：A 给谱分析含一种七和弦的 4–8 小节片段；B 无谱扒 2–4 小节简单旋律及基础三和弦骨架，可先给根音或候选集；最终加一次无提示的新短例，不把分析能力与完整听写混为一项 |

顺序依据：先解决概念到指板的对应，再建立音阶级数与调性语境；三和弦提供和弦音的参照，调内和声解释连接；随后用五声音阶服务旋律，再扩展七和弦，最后综合。听觉和演奏从第一节就出现，但各节都有明确概念讲解，不要求学习者自行从曲子里归纳全部规则。

## 每节固定教学结构

1. 简短检索上一节内容，记录独立首答。
2. 讲清本节一个核心关系，给最小声音/谱例。
3. 由教学者示范分析一个有代表性的作品片段。
4. 学习者在引导下听、标、弹；错误反馈说明关系。
5. 撤去提示，换材料完成同范围任务。
6. 下一次学习前用另一例复测；薄弱项补练，不整节重复。

节奏贯穿所有材料，但第一轮控制为简单拍号和已能模仿的节奏。若诊断发现节拍会阻碍任务，先加短补课；不把节奏或演奏技巧失误直接判为音高概念不懂。音名+级数为主，六线谱提供位置辅助，必要时配五线谱，不把流畅五线谱视奏设为新门槛。

## 材料选择规则

- 每节准备四种用途的材料：最小自编示例、已核对的真实作品节选、引导练习、独立测试。测试不复用教学答案。
- 真实作品以能清楚呈现本节关系为先，不因知名而选；选定具体版本后核对谱与音频。当前只定义选材条件，尚未完成具体曲目选定与核谱。
- 前几节每例约 2–4 小节，节奏、速度、音区和演奏难度受控；同一作品可跨课回看，但独立检查必须换例。
- 比较和弦性质时尽量控制音色、力度、音区和排列；随后在真实片段中观察语境差异。主观听感描述不要求统一形容词。
- 扒歌材料先用声部清晰的教学录音，再进入密集制作的真实录音；不能把教学录音上的成功外推到所有歌曲。
- C/G 大调与 Am/Em 是初稿选材范围，不要求把所有音阶、所有调都学完再开始应用。

## 如何判断课程有没有帮助

分别记录结构理解、听觉应用、吉他操作，不合成一个“通关分”。每次记首答、错误类型、求助与修正；同一题反复尝试后的正确不算独立掌握。

建议的进阶依据：本节核心关系能解释，在两个不同新实例中完成应用；下一次学习时另换实例复查。此数量仅用于首轮观察，不是经验证的熟练度阈值。听觉任务需单独保留证据，书面通过不代替听觉通过。

课前、课后和结束后约一周，用难度相近、答案不同的短片段比较独立完成情况和错误类型；时间只作辅助，不强制限时。允许循环与参考音的范围保持一致。若出现“公式会、找音不会”，补指板映射；“分析会、听不出”，补声音对照和模仿；“原例会、新例不会”，补变式，不先增加新知识。

课程成功只支持用户在这类材料上的初步应用进步，不能证明适用于所有学习者、已经长期掌握或可以独立编曲。个人喜欢的歌曲在统一材料之后作迁移观察，不用于组织全部课程。

## 后续待细化，不阻塞本稿

- 诊断后调整补课与跳过内容；当前指板熟悉度、听觉模仿与简单节奏能力尚未实测。
- 选定各节具体曲例、练习和标准答案，尤其控制吉他指法难度。
- 先制作一节完整教案并实际试学，之后再决定网页承载方式；本轮没有网页实现任务。
- 编曲方向另设后续课程，涉及声部、节奏型、织体、结构与配器；不以完成本课程代替编曲训练。

## 课程依据与边界

2026-11-04 查阅。以下来源用于核对知识关系与课程覆盖，不构成对本稿效果的证明，也不是照搬其完整教学顺序。

- [Berklee Online：Music Theory 101](https://online.berklee.edu/courses/music-theory-101)：公开课程覆盖音高、音阶、音程、三和弦、七和弦及其应用。本文结合用户已有概念基础重新组织。
- [Berklee Online：Guitar Scales 101](https://online.berklee.edu/courses/guitar-scales-101)：将音阶与吉他演奏应用联系，且设基础知识前提；本文不采用其全部音阶范围。
- [Open Music Theory：Triads](https://viva.pressbooks.pub/openmusictheory/chapter/triads/)：三和弦性质、组成与调内级数关系的事实核对。
- [Open Music Theory：Collections and Scales](https://openmusictheory.github.io/scales2)：音集合、音阶与五声音阶关系的事实核对。
