# 实施范围
新增 app/public/course/{index.html,app.js,model.js,style.css}，数据由 curriculum.js 提供。独立目录保留第一章入口与原记录，不修改第一章业务。共用探索播放器，听觉无目标高亮。

## 验收与行为
- Given 未作答题，When 首次提交再重试/提示，Then 封存首答并分别记次数和辅助。
- Given 听觉题，When 参考取消/失败/切页，Then 不取得完整播放资格；试弹和慢放不标帮助。
- Given 完成独立应用及听觉，When 下一自然日访问，Then 解锁不同复测材料，完成日不改写。
- Given 已开始未完成题，When 教学/知识页面访问，Then 记录辅助；未开始题不创建辅助记录。
- Given 刷新，When 恢复本章，Then 继续步骤和题目；异常JSON/成员/记录结构备份原文并明确提示。

## 界面
章节目标、分步文本与示范、两类选择/六弦0–15品定位、候选试听、普通/慢速播放、分项记录与实琴建议。隐藏声音题仅展示候选，绝不从答案渲染颜色、音位或可访问性提示。听觉失败反馈不透露正确项。结果不宣称实际学习有效。

## 验证
model 公共行为测试先失败再实现，4/4通过；覆盖首答、提示与失败门槛、自然日完成封存、跨页访问帮助。浏览器由验证Agent执行并汇总。真实听感、实际学习、真机与实琴均未验证。

补充验证：`node tests/course-race-browser.mjs` 通过。通过播放器公共接口注入故意延迟且忽略 stop 的返回，确认切章后旧参考不能解锁新题、不同章节相同题 ID 相互隔离、完成状态刷新恢复。这是取消竞态的确定性验证，不是真实音频验证。正常/慢速共用参考和候选的时值倍率，不标提示；目标与有琴实践建议已呈现。

审查修复：目录/首页纯导航不再误记辅助；每章按题保存 started 基线，知识访问覆盖所有已开始未完成题，未开始题不创建记录；实琴建议只在教学、引导与记录页显示。新增公共规则测试先红后绿，合计 6/6。浏览器验证 Agent 接手实际 UI 回归。
