# 初学者阶段试学路径

本轮“初学者”指已有音程/音阶/和弦概念，但尚未能稳定用于指板和听觉的学习者，不指从零记名词。

建议顺序：第一章复测 → 第二章级数与换主音 → 第三章主音证据 → 第四章指型拆音 → 第五章调内和弦与旋律落点 → 第六章五声旋律 → 第七章三种基础七和弦 → 第八章简单分析与受限扒歌。
每章可以分多次学，不计速度。独立题前先做引导；隔天用新题复查。错误后修正有价值，但与独立首答分开记录。

## 边界
学完应能在教学级、无转调、简单节奏片段上解释候选调性和和弦关系，尝试按级数找音、移调短句，利用参考音和候选缩小扒歌范围。不能据此宣称全指板熟练、无参考音绝对音高、复杂节奏听写、任意录音完整扒谱或编曲。

## 用户试学时观察
- 能算但定位慢：允许慢慢推算，补同一关系的不同弦位置。
- 能选文字答案但声音拿不准：记录听觉项，反复比较，不用关系题成绩代替。
- 能做当堂题、隔天新题不稳：回到相关示范，不追加新概念掩盖困难。
- 有琴后：按页面建议弹出、换起音并解释，另记真实演奏观察；屏幕点击不代替实琴。

课程完成数只是网页任务记录。学习效果、真机触控、实琴及长期保持仍需真人试用，不能由自动化测试宣布通过。
