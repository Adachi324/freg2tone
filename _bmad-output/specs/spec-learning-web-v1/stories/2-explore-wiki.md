# 探索与知识阅读
使用现有纯函数 model.js、DOM app.js、共享文章 wiki.js；不引入框架。测试 seam 为乐理公共函数与实际用户操作。
范围：12 个主音的大调；大、小三和弦使用可移动 E 型与 A 型横按，0–12 品内完整指型，无完整指型则明确提示。音阶采用每弦三音（3NPS）：从六弦各个调内音起，沿音阶连续上行，每弦三个音，过弦后接下一音，形成 18 音指法。只保留六弦完整且不超出 12 品的把位，不用矩形区间切片。当前把位按与和弦实际按弦点平均品位最近匹配，同距取低；相邻为排序前后一个。共同音位显示多色分段并列说明，和弦轮廓最高优先。非调内和弦不关联，保留和弦提示。
Given 空白初访 When 打开 Then 无内容叠加；Given 设置 When 改值并关闭 Then 即时效果保留；Given 已加和弦 When 改调 Then 保留指型并更新关联；Given Wiki 往返或旋转 When 返回 Then 状态恢复；Given 边界 When 邻位不存在 Then 明确说明缺失，不编造。
修改 app/public/explore/{model,app,knowledge,wiki}.js、index.html、style.css，Wiki复用同一文章和视觉。保留既有导出兼容测试。

映射是本工具的空间邻近辅助算法，不宣称是官方 CAGED 对应。每弦三音按实际半音与标准调弦生成，可能需要四品跨度伸展；不保证初学者无伸展演奏。
