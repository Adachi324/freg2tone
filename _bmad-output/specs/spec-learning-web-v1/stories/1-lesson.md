# 范围与实施
保留 mg-lesson-one-v1 数据键和原有题集、首答封存、完成日期。新增起点诊断自由文本首答（允许不知道），学习曲例解释、引导练习与按需指板，统一粉橙玻璃视觉。

Given 未完成独立题，When 打开教学、引导或外部探索/Wiki，Then 当前题永久记为得到帮助，首答不覆盖。
Given 声音失败或播放被后台打断，When 提交听觉题，Then 拦截且不计次数。
Given 当堂两组完成，When 下一自然日访问，Then 开放原有未在当堂题集中出现的复测。

## 剩余审查
新记录 version 2 增加指定弦约束：前两题单弦，末题从 3 弦 C4 向 2 弦迁移。旧记录无 version 时继续沿用任意显示弦同音判定，不改历史含义。关系理解由诊断文字保留，不自动评分。

主审修复：辅助指板完整显示标准调弦六弦；指定弦提示去除“任意弦”矛盾。关系题错误反馈提供所选距离和推算方法，保留首答；听觉题仍只提示重新比较，不透露目标。格式异常的旧原始数据保留到 `mg-lesson-one-v1-invalid-backup` 并在页面明确提示。停止按钮保留此前完整听参考的资格；新一次参考开始即清除资格，中断不恢复；切页与后台清除资格。
跨标签帮助修复：保存实际已开始题目 activeId 与资料访问基线 helpSeen；在刷新、focus、storage 事件读取共享访问时间戳，仅将实际开始且未完成题标为辅助，避免正确提交后误标尚未开始的下一题。新增行为测试先红后绿，规则合计 4/4。
最终审查修复：教学分为“距离与度数 / 只改变一个音 / 旋律与跨弦”三个知识点，通过前后按钮逐步呈现，learnStep 刷新恢复；引导练习分可见提示与提示默认收起两阶段，guidedStep 保存，之后进入独立应用。旧首答值仅接受 null 或有限 0–127 音高，异常原始数据仍备份。构建与规则 4/4、脚本语法检查通过，交由验证 Agent 重跑浏览器。
