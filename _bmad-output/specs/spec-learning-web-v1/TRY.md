# 首轮试学

本地运行入口：http://127.0.0.1:8877/lesson-1/ 。自由探索 /explore/，知识阅读 /wiki/，原游戏 /。

服务停止后：在 app 目录运行 `npm run build`，再运行 `npm run preview`。使用构建预览服务访问目录入口。

1. 起点诊断：写自己的推算或选择不知道，不要求速度。
2. 看与听：依次比较距离、三音变化与小星星五度跳进，按需展开指板。
3. 引导练习：先按提示选音，再收起提示比较。
4. 换起音：依指定弦定位；独立听觉：完整听参考后试弹比较，再提交。
5. 查看记录：分别看首答、提示与重试，不把完成等同掌握；下一自然日再做新题。

测试中查阅教学或知识会记录辅助，反复试听不会自动记帮助。已有记录保留；建议沿用同一浏览器与同一地址，localhost 与127.0.0.1属于不同存储来源。

未验证：用户实际学习效果、隔天保持、人耳听感、真实手机与实琴。Codex内置浏览器连接失败，当前截图及交互证据来自自动化Chromium模拟。
