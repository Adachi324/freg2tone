## 2. Medium：正确提交后的回看是否计为辅助没有统一截止点

位置：implementation.md第30、37、39、45行；ARCHITECTURE-SPINE.md AD-2。

失败场景：玩家未求助地正确提交三音序列，在播放结束前打开回看。实现A在有效正确提交时标记completed，因此后续回看不改变独立完成；实现B在playbackFinished时标记completed，此前按“打开含答案对照即置helpUsed”把结果改为辅助完成。两者都保持firstSubmission不变、都只由game写状态，却对同一次玩家行为给出不同完成方式。

最小修正：明确证据在“首次有效正确提交被接受”时冻结；提交后的回看不再改变该题完成方式，播放完成只控制反馈/继续/开桥。也可明确禁止该窗口的回看，但前一种保留现有暂停语义且无需新交互。加一个公共规则接口用例验证“正确提交→播放中回看→恢复完成”的分类不变；错误提交后回看仍能影响后续成功的辅助分类。
