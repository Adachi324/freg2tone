- (assumption) 助手关卡提案：同一机关渐进练习单音关系；挑战包含打乱位置的唱名→音名、音名→唱名各一次，以及未在示范照抄的三音序列。序列持续显示，无节拍命中/听写要求；固定均匀时值只作播放。可复用同一材料，不限制重复音；最多三个槽位，不建题库引擎。
- (assumption) 助手评估提案：记录首答、错误次数、提示与重试，答案若被帮助/错误解释揭示，则该实例计为辅助或反馈后完成；新的任务实例可再观察独立应用，不覆盖前次证据。通关可重试，不强迫无错重开整节。颜色、位置和可听预览不得暴露另一个名称而绕过映射。
