# 教学与挑战设计

2026-10-30。用户已认可并授权开发，三个增量功能已实现；软件最终回归、真机与学习效果状态见验证记录。沿用当前认可的立体花园与纸面教学，不新增场景。具体固定题目、暂停和记录口径以implementation.md为准。

## 学完能做什么

玩家知道本节同一个音可以用字母音名和唱名标记，并在C大调限定情境下完成C/do、D/re、E/mi的双向对应；能按可见的三音唱名序列选出音名材料，听到并看到自己的选择作用于机关。

本节不要求听一个孤立音就知道它是什么，不考演唱、节奏、乐器键位，也不把“熟记三个对应”夸大成理解调性。

## 内容正确性边界

学习者看到的短说明可为：“材料上的C、D、E叫音名。do、re、mi是唱名，可以用来唱这些声音。这一节在C大调中练习：C对应do，D对应re，E对应mi。先听听看，再让这些声音帮小拍开路。”C大调在此仅作为适用条件，不要求先学习调的定义。

示范把两种标记显示在同一材料上，并播放同一音；切换标记不能改变音高。所有示范、题目和结果共用此映射；本节使用同一音区，不引入八度差异。

固定唱名与首调唱名的对应规则不同，不能写成“C在任何情况下都叫do”。本节的C大调范围不需要提前选择整个课程的体系。乐理核对依据：[Sierra College / Lauren C. Sharkey：Solfège Methods](https://human.libretexts.org/Courses/Sierra_College/Equipping_the_Musical_Ear/01:_Pitch/1.03:_Solfege_Methods)，2026-10-30查阅；仅用作事实核对，教材图片、录音和原文不作游戏资产。

## 一次体验

| 环节 | 玩家看到、听到与做到的事 | 要验证的事 |
| --- | --- | --- |
| 进入 | 看见挡路的桥；点机关，角色靠近后展开说明 | 目标与操作对象清楚 |
| 介绍 | 看上述短解释：字母和唱名是本节声音的两种标记，有明确语境 | 知道学什么、为什么有用 |
| 对照示范 | C/do、D/re、E/mi逐一同步出现并发声；点击可复听 | 两种标记不是两个声音 |
| 引导练习 | 机关请求do、re或mi，玩家选择音名材料放入；对应表可回看，逐步撤去答案提示 | 三个关系均有亲手应用机会 |
| 独立挑战 | 收起说明后改变任务与材料排列，进行下表三种任务 | 运用关系，不能照抄位置 |
| 结果 | 正确组合依次发声，机关完成动作、桥落下、角色通过；可复听并复玩 | 操作与结果因果清楚，保留本次完成方式 |

介绍/示范/练习合计3–5分钟、整体约10分钟只作编排目标，实测后调整；不靠强制等待或增加重复题凑时长。纸声保持轻量，不能覆盖示范音；无声时用同步标记与顺序动效承载信息。

## 独立挑战的具体例子

以下题例用于说明判定方式。实现时可换顺序，但不能只把引导题原样重放。

| 任务 | 指令与可操作材料 | 正确结果 | 场景反馈 |
| --- | --- | --- | --- |
| 唱名→音名 | 机关需要re；材料C、D、E | 选择D | 音响与一处锁扣响应 |
| 音名→唱名 | 机关给出E；材料改为do、mi、re标签，并先说明标签换成唱名 | 选择mi | 同一机关另一处锁扣响应 |
| 组合应用 | 可见指令mi—re—do；音名材料D、E、C，三个顺序槽位 | E—D—C | 播放玩家组合；正确后开桥并通行 |

场景仍是一套机关，具体锁扣造型属于后续实现细节。每个材料可重复使用，例如未来复玩出现do—mi—do时允许C—E—C；不能把“每个材料各用一次”变成隐含答案。只在玩家主动试运行时判定序列，提交前可替换任意槽位。

序列始终可见，避免把记忆指令长度当作音名学习；均匀播放仅方便对照，不引入节拍命中。挑战材料的可听预览可以保留，但不能同步显示另一种名称泄露答案；颜色不能在指令和材料间暗示一一配对。

## 错误、求助和记录

- 未选择或槽位不完整：提醒补全，不判乐理错误。
- 已提交但不正确：保持场景和当前组合，指出需要再检查的关系，允许替换。不扣生命、不强迫重做整节。
- 本题尚未正确提交时，回看或解释如果展示了对应答案，该实例标记辅助；正确提交接受后封存记录，播放期间或之后回看不追改；已经给出错误反馈后再成功，记为重试后完成。两者均不冒充首次独立成功。
- 新实例可以继续观察是否独立应用，但不抹去先前错误/提示记录；复玩只重置新的尝试。
- 教学、帮助、暂停与声音行为沿用已验证样本；这不是对iPhone后台和音频行为的验收结论。

## 怎样验证“学到了”

首轮记录只留当前体验所需的题目、首答、错误与帮助情况，不为研究建后台或分析平台。人工观察表也足以起步。

1. 对本来不懂的试用者，在教学前给一个简短同范围基线问题，允许回答“不知道”，不先泄露答案。
2. 教学后撤去对应表，用不同实例与顺序检查三个音，并让玩家用自己的话说明一个选择理由。不能仅因随机尝试终于过关就判定学会。
3. 区分独立首答、重试后完成和借助提示完成。程序只判断答案与过程记录；解释理由由试用者反馈，不新增AI判卷或麦克风采集。
4. 已懂这些内容的用户用于验证流程、反馈与内容表达。对其学习提升暂不下结论；后续用陌生和弦内容及延后复测验证更强主张。
5. 无声只能验证标记关系与组合应用；声音跟手另测，听觉辨识和长期保持不属于本轮通过条件。
