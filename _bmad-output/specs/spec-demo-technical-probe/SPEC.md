# 首个 Demo：最小技术样本

> 由本工作区 `.memlog.md` 及其引用输入提炼。本规格与伴随文件共同定义探针合同；上游已确认方向沿用，未采纳提案不自动进入范围。技术探针不替代正式教学 Demo，也不锁定产品架构。

## Why

首版技术样本已跑通，但用户认为整场2D→3D翻转缺少用途。本轮验证固定立体花园内的纸面教学与机关实践能否自然衔接，手机触控、声音与反馈仍需真机检查。先在一个有限样本中取得运行证据，再决定是否沿用候选技术和素材路线制作完整学习单元。

## Capabilities

- **CAP-1**
  - **intent:** 玩家在立体花园中的平面教学区域阅读说明、观看示范并亲手操作音乐材料。
  - **success:** 说明、可重播示范、玩家练习均可实际执行；标记与声音对应，材料操作产生反馈，不以自动演示代替练习。
- **CAP-2**
  - **intent:** 玩家完成练习后收起教学，在同一固定立体场景中主动开始挑战。
  - **success:** 从初见到完成镜头保持固定；收起教学后立即能选择材料，练习选择不带入挑战。真实几何、遮挡与桥运动可检查；减少动效不影响完整流程。
- **CAP-3**
  - **intent:** 玩家通过材料驱动机关，能原位重试、回看说明及重新体验。
  - **success:** 错误不会通行；成功后桥先就绪、角色再通过；回看保留尝试并标记辅助；重复输入不会重复判定或通关。
- **CAP-4**
  - **intent:** 玩家在主测手机上有声或无声体验，能处理暂停、恢复和运行失败。
  - **success:** 横屏操作可达；切后台、打开说明或转竖屏时停止场景操作；恢复不补播旧声；声音不可用时仍可操作，资源/渲染失败有可见恢复入口。

## Constraints

- 一屏、三枚材料、一套机关、同一固定立体场景；点选目标后角色自动靠近，材料直接操作，挑战镜头固定。
- 主测 iPhone 13 Pro Max，横屏触控优先；PC 鼠标遵循相同行为。桌面缩放不替代真机验收。
- 保留已认可教学 UI、场景构图与失败/成功反馈方向；清晰墨线、柔和中等亮度配色，弱化实体书；文字不得烘焙到背景而失去可读性。
- 立体机关必须有真实几何及运动；整图淡入淡出不能构成 3D 验证。素材需留下可编辑来源。
- 同一规则状态驱动声音与画面；无声反馈表达结构，不作为听觉学习证明。
- 实现边界见 `implementation.md`；测试分工、设备记录和初始排查线见 `acceptance.md`。历史工程验证见 ../../implementation-artifacts/probe-verification.md；本轮结果单独记录，真机验收尚未完成。

## Non-goals

- 完整教案、唱名体系、学习效果验证、第二关、自由探索和自由镜头。
- 账号、后端、跨设备同步、正式持久存档、关卡编辑器、麦克风识别。
- 完整 Playground、战斗、EX 关卡、乐队、原生打包和全平台兼容承诺。

## Success signal

用户在 iPhone 13 Pro Max 上在同一立体场景完成说明与练习后进入挑战，完成一次错误重试及一次成功通行；能自然从纸面教学回到场景操作，并认可手绘观感与声音/操作反馈。规则、浏览器和真机检查有可复查记录，才能判定候选路线值得继续；仅代码检查通过记为待真机验证。

## Assumptions

- 用 TypeScript + Three.js + HTML/CSS + Web Audio、Vite vanilla-ts 做可回退探针，不是正式产品选型。
- 首轮浏览器暂按 Safari；系统和浏览器版本在测试时记录。
- 临时 C/D/E 材料和 C 目标仅用于测试；点选再放置、帮助覆盖当前场景、暂停恢复等细节按伴随文件的工程默认实现，接受体验反馈后调整。
- 44 CSS px 命中区和帧时间排查线是本轮提出的起始预算，未获实测支持，不是产品性能承诺。

## Open Questions

- 真机验收时：实际 iOS/浏览器版本及手机可访问的测试地址是什么？实现阶段补齐，不阻塞本规格。
- 动态样本完成后：用户是否认可手绘观感、教学/挑战衔接和声音手感？必须保留为实际体验评审，不能提前判通过。

## 已确认修订（2026-10-16）

用户认可取消每关固定2D→3D翻转；保留平面教学与立体互动，维度切换仅在未来玩法确有用途时再考虑。Story 2接续Story 1，旧版规格执行记录与截图作为历史证据保留，不作为当前行为要求。
