- (capability) CAP-1 平面说明与练习：玩家在同场景阅读说明、观看可重播的声音/标记示范并亲自操作；通过依据是三者均能实际执行且材料操作有反馈，不以自动演示代替练习。
- (capability) CAP-2 连续进入立体场景：一次主动进入挑战将同对象展开到真实3D，结束后固定镜头；通过依据是实际几何与遮挡/桥运动可见、身份稳定、转场无操作穿透，减少动效时可到达同终态。
- (capability) CAP-3 机关尝试与复玩：选择材料后放入槽位，失败保留上下文可替换，成功桥动作完成后角色通过；回看保留尝试并标记辅助，复玩重新开始，重复输入不重复提交或通关。
- (capability) CAP-4 设备声音与中断恢复：iPhone 13 Pro Max 上可有声或无声操作，后台/教程/方向改变时暂停，继续后不补播旧声；加载/渲染失败有可见重试入口，保留声音不可用时的无声路线。
- (assumption) 探针采用 TypeScript+Three.js+HTML/CSS+原生Web Audio+Vite vanilla-ts 作为可回退实现方案，不代表最终产品选型；不沿用预研latest为锁定版本，实施时核对官方安装要求并记录实际依赖。Safari暂默认，iOS/浏览器版本实际测试记录。
- (assumption) 暂用C/D/E三种材料和固定C目标作为可预测技术夹具，不教授唱名映射、不证明学习；示范/引导后挑战变更材料排列，帮助看同一说明并标记辅助。先点材料再点槽，同材料再点取消。单次短音频可替换旧音，音乐与纸张拟音分开控制。
- (decision) 样本内部职责为纯规则状态转换、DOM/Three场景呈现、音频；单一逻辑状态，使用稳定materialId和attemptId，规则不依赖网格坐标。动画完成事件推进规则，过期事件忽略。全部会话内存，刷新重来，不决定正式存档。
- (decision) 关键状态：loading→intro→demo→practice→transition→challenge→resolving→complete；点目标时角色自动走预设路径，抵达才展开说明。overlay=help/portrait/suspended互斥优先级为suspended>portrait>help；覆盖层阻止场景输入并暂停动作。解锁音频失败可无声继续，恢复只重建未来事件。
- (decision) 失败保持challenge且记录失败材料；选中状态可替换，成功resolve中禁止新提交，桥就绪后才允许角色通行。完整复玩清除尝试及帮助记录并回到intro，重试不重复转场；返回前台需继续手势，转场恢复从已保存进度继续且只发一次完成事件。WebGL丢失中止渲染/声音并显示重载入口，刷新不恢复进度。
- (constraint) 教学DOM不能穿透场景；横屏适配实际viewport与安全区，主要操作命中区至少44×44 CSS px且互不重叠（探针工程默认）；竖屏显示转横屏提示、暂停、不提交操作；减少动效直接落到等价最终状态。
- (decision) 资产只做简化角色、三个材料、一槽、活动桥和必要地面；真实机关几何与手绘表面，远景可分层插画。保存可编辑源/生成脚本及贴图来源；保留墨线、中等亮度、柔和色块和纸张拟音，不把整张概念图作为模型或动画序列。
