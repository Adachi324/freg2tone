# 探针实现边界

本文件的具体行为是探针工程默认，不冒充此前用户逐项确认。正式 Demo 仍需知识介绍、对照示范、引导练习、独立挑战和结果的完整教学设计；本样本只检查这些载体能否运作。

2026-10-16：本文件已按用户反馈修订。花园始终立体，教学面板开合是呈现动效，不再设置等待维度切换的规则阶段。

## 临时内容与素材

沿用已认可的场景构图：左侧说明空间、角色、三枚材料、单槽机关、活动桥及出口。C/D/E 是稳定材料标识，目标固定 C；解释它们是不同音的字母名称，示范时对应标记与音响一起出现。不给出未决定的唱名映射，也不把字母匹配称为乐理掌握。

示范、练习及挑战复用同一组材料，挑战改变排列。先做几何和状态，再给同一小块场景加手绘表面；最终探针必须提供风格样本，灰盒只能交付技术阶段结果。桥、地面、机关为真实几何，远景可用分层插画；不要求所有物件连续形变。

保存几何生成脚本或模型源、贴图来源、枢轴和动作说明。现有完整插画仅供构图/风格参考。纸张拟音用于说明开合，音乐音色用于材料；两者分控，示范发声前结束拟音，不增加背景乐或音乐编排系统。

## 一次完整操作

| 阶段 | 进入与行为 | 离开条件 |
| --- | --- | --- |
| loading | 准备必要资源；失败显示原因和重试 | 资源与渲染可用 |
| intro | 玩家点机关，角色沿预设路径靠近，抵达后展开说明；提供有声开始与无声继续 | 玩家读完并主动看示范 |
| demo | 文字解释、标记和短音同时演示，可重播 | 玩家进入练习 |
| practice | 玩家点材料，再点槽位尝试；错误留在练习 | 正确后出现“收起说明，开始挑战”入口，点击即进入挑战并清空选择 |
| challenge | 保持初见时的固定立体镜头，材料重排，仅保留简短任务签；可回看，无逐步答案提示 | 正确提交进入 resolving，错误仍在原地 |
| resolving | 材料入槽，桥打开；桥就绪后角色通行，禁止新提交 | 角色抵达出口 |
| complete | 显示本次结果，区分辅助/独立操作，允许复玩 | 复玩回到 arrival 并重置本次状态 |

点选另一材料替换选择，点同一材料取消；未选材料点槽只显示操作提醒。错误保留失败材料与上下文，允许换材料；不播放通关动作。场景空白点击不提交。一次触摸只形成一次命令，`pointercancel` 不提交。

帮助只覆盖当前场景；关闭恢复相同阶段、选择和尝试，不重置场景。挑战中求助标记为辅助，关闭不清除；完整复玩才清除。失败重试保持原地；完整复玩回到立体花园初见，再次靠近并阅读教学。

## 暂停与异常

覆盖状态优先级为 `suspended > portrait > help`；显示覆盖层时，场景输入与动作均暂停，音频停止并清空未来旧事件。恢复须在页面可见且横屏时进行；后台回来提供明确的“继续”手势，音频恢复失败可以无声继续。靠近/桥/角色动作保留暂停位置，继续推进，完成事件只发一次。

竖屏显示转横屏提示，不强制系统锁屏；旋回横屏后恢复操作入口。说明开合、浏览器地址栏变化和 viewport 改变后更新布局及拾取映射。关键 UI 避开安全区；主要按钮及材料有效命中区至少 44×44 CSS px，邻近命中区不重叠。说明内容可在自身区域滚动，不能把点击传到场景。

声音等待用户手势启用；音乐/拟音分别有开关。快速预听采用替换上一短音的有限播放策略，停止时短包络收尾，不无限堆积声音。反馈用同一事件的音频时刻驱动；静音时用视觉时钟完成相同行为。重播示范只重播当前示范，不改变尝试结果。

资源失败提供重试；WebGL 不可用显示明确说明；context 丢失停止声音与场景并提供重载入口。重载会清空本次进度，提示须说明。先做到失败可辨认、可重新开始，不增加复杂 GPU 状态恢复。

## 代码与数据边界

仅使用一个应用和三个职责：纯规则状态转换、DOM/Three.js 呈现、音频播放。角色移动采用固定路径，不引入物理/导航、通用关卡框架或跨引擎抽象。模型/贴图可替换，但材料身份及规则不读取网格位置。

最小逻辑状态：`phase`、`selectedMaterialId`、`attemptId`、`lastAttempt`、`helpUsed`、`overlay`、声音偏好；呈现层另存动画进度。音频是否已解锁是运行状态，不是题目规则。材料记录包含稳定 `id`、可读标记及声音参数，临时目标放在内容配置中。

规则入口接受 `select / submit / showHelp / hideHelp / enterChallenge / replay / pause / continue` 等命令，输出新状态和带 `attemptId` 的反馈事件；呈现完成再回传 `arrived / bridgeReady / exitReached`。按阶段和尝试标识拒绝过期/重复完成事件，避免暂停或复玩后旧回调推进新流程。

音频消费事件，不另行判题。渲染负责将命中转换为材料身份；DOM 面板事件不得进入场景命令入口。规则可脱离浏览器与 WebGL 单测，实际拾取和音频生命周期留给浏览器/真机验证。

## 运行与交接

探针候选为 TypeScript + Three.js + DOM/CSS + 原生 Web Audio，Vite vanilla-ts 起步。实施时核对官方安装要求和环境、记录并锁定实际依赖；预研中的版本快照不自动当作已安装依赖。Babylon.js 保留备选，不并行开发两套。

静态构建、会话内存状态，刷新从头开始；这不决定正式产品存档方案。先本地运行，真机验收前准备手机可访问的地址与操作说明；不得用开发电脑的 localhost 链接冒充手机可访问地址。部署服务、域名和正式发布不在本规格内。

交付运行入口、构建方式、依赖锁文件、资产来源和验收记录；后续依照 Story Breakdown 与 bmad-build 进入实现。探针结果回写预研和 UX 后，再收敛正式 Demo 架构及内容规格。
