## 体验顺序

横屏打开 → 点右侧机关 → 阅读介绍 → 听听看或无声继续 → 练习选C并点槽 → 让花园展开 → 故意选D再改C → 观察开桥和角色通行。可另试回看、声音开关、后台回来与复玩。
